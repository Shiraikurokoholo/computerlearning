# 用指针修改原变量

有时函数要帮另一段代码修改一个变量。把变量的地址交给函数，函数就能找到它原来的位置。比如把已有的号码从 10 改成 25。

## 逐行读代码

完整程序在编辑区和 `examples/cpp_pointers.cpp`。

```cpp
void update_number(int* target, int value) {
    *target = value;
}
```

- `void` 表示函数执行完后直接结束，调用处无需接收返回值。
- `int* target` 接收一个指向整数的指针，可以把它想成保存整数所在位置的便签。
- `*target` 访问指针指向的整数，`*target = value` 把新值写到那个位置。
- `update_number(&number, 25)` 中的 `&number` 取出 `number` 的地址，所以修改后 `main` 再读 `number` 会得到 25。

可以在纸上画一个名为 `number` 的格子，再画一条从 `target` 指向它的线。运行函数时，沿线走到格子里改值。

## 示例输入与输出

输入区留空。输出

```text
修改前：10
修改后：25
```

## 常见错误

- 调用时写成 `update_number(number, 25)`，第一个参数传去的是整数。加上 `&` 才能传入地址。
- 只有指针指向可用变量时，才能用星号访问该位置。使用前先确认地址来自哪个变量。

## 动手练习

### 基础练习

把调用中的 25 换成 42，预测两行输出，再保存个人代码运行验证。

### 进阶练习

在 `main` 中另建一个整数变量，把它的地址传给函数。分别打印两个变量，判断写入发生在哪一个格子。
