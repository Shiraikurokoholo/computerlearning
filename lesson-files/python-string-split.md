# 把一行文字拆开

`strip()` 去掉两端空白。想把整行按空白拆成若干词时，用 `split()`。多打几个空格也会得到同样的一排词。接下来一章会用列表来保存这些拆开的词。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_string_split.py`。

```python
# 用空白拆词，再用斜线把词连成一句。
text = input()
words = text.split()

print(f"词数 {len(words)}")
print(" / ".join(words))
```

1. `input()` 先读取原样的一行文本。
2. `text.split()` 把空白间隔两边的文字取出来，存成一排词。
3. `len(words)` 统计词的个数。
4. `" / ".join(words)` 用 ` / ` 把每对相邻的词连起来，开头和结尾都不会多一条斜线。

## 示例输入与输出

输入

```text
猫  狗 猫
```

输出

```text
词数 3
猫 / 狗 / 猫
```

## 常见错误

- `.split()` 会合并处理连续空白。`.split(" ")` 明确指定每个空格的位置，连续空格可能拆出空字符串。
- `join()` 的左边是分隔文字，括号里放要连起来的词。

## 动手练习

### 基础练习

试只有一个词和全是空格的输入，留意全空格时最后一行为空。

### 进阶练习

把分隔符改为 `、`，再运行默认输入，核对三项之间的标点。
