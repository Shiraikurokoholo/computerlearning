# 变量与输入输出

在上一课，程序打印事先写好的问候。这次让它读入名字和年龄，再算出明年的年龄。相同的代码可以对不同的人给出回答。

## 用名字保留数据

把 `name` 想成一张写着“名字”的标签，程序稍后用这张标签取出读到的文字。给变量赋值时，先计算等号右边，再把结果和等号左边的名称关联起来。

`input()` 每次读取一行文字。例如输入 `18` 时，读到的是字符串 `"18"`。要做年龄加法，先用 `int()` 转成整数 `18`。

## 逐行读代码

完整程序在编辑区和 `examples/python_io.py`。

```python
name = input().strip()
age = int(input())
next_age = age + 1
print(f"你好，{name}！")
print(f"明年你就 {next_age} 岁了。")
```

| 语句 | 用自己的话读 |
| --- | --- |
| `name = input().strip()` | 读入第一行，用 `.strip()` 去掉两端的空白，然后给这段文字起名 `name`。 |
| `age = int(input())` | 读入第二行，将它转成整数并保存为 `age`。先执行最内层的 `input()`。 |
| `next_age = age + 1` | 用保存的年龄做加法，把结果保存为 `next_age`。 |
| `print(f"你好，{name}！")` | 引号前的 `f` 让 Python 把大括号内的变量代入句子，打印名字。 |
| `print(f"明年你就 {next_age} 岁了。")` | 用同样的方法打印算好的年龄。 |

## 示例输入与输出

在测试输入区分两行填写。也可以在终端运行程序后，逐行键入并回车。

```text
小明
18
```

输出

```text
你好，小明！
明年你就 19 岁了。
```

## 常见错误

- 把名字和年龄写在同一行，会被第一次 `input()` 一起读走。第二次 `input()` 仍然需要一行。
- 把第二行填成 `十八` 或 `18.5`，`int()` 会报告 `ValueError`。这个例子要读一个可以转换为整数的字符串。
- 忘了写 `f` 时，输出里会保留 `{name}` 字样。结果出现大括号时，可以检查引号前面。

## 动手练习

### 基础练习

用你的名字和另一个整数年龄运行示例。把年龄换成 `十八`，在错误信息里找到 `int(input())` 和 `ValueError`。

### 进阶练习

将个人代码改成计算五年后的年龄，同时修改输出文字。把 `age + 1` 换成 `age + 5` 后，用输入年龄 18 核对结果是否为 23。
