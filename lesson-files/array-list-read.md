# 顺序表读取与越界

上一课的表从左到右是 10、20、30、40。今天只做一件事：**给一个下标，取出那一格的号码**。先输入 `2` 运行，看看为什么输出 `30`。

## 先想一遍，再读代码

1. 表长是 4，可读下标是 0 到 3。
2. 下标 2 在范围内，可以直接用 `values[2]` 取到 30。
3. 下标 4 已经越过表长。程序先给提示，再结束。

## 逐行读代码

完整程序在右侧和 `examples/array_list_read.cpp`。先看下面两句，它们分别是检查和读取。

```cpp
if (index < 0 || index >= length) {
    std::cout << "读取失败：下标超出范围。\n";
    return 1;
}

std::cout << values[index] << '\n';
```

- `index` 保存输入的下标。`||` 读作“或者”。下标小于 0，或者大于等于表长，都会进入 `if`。
- `cout` 打印一句提示，`return 1` 随即结束程序，后面的读取就不会执行。
- 输入有效时，`values[index]` 直接取对应的格子。`cout` 把号码打印出来。

程序前面的 `cin >> index` 负责读整数，`cin.fail()` 检查刚才是否读失败。可以先用整数输入练习，把这段当作入口检查。

## 示例输入与输出

输入

```text
2
```

输出

```text
30
```

## 常见错误

- “第三个”对应下标 2。输入 3 会读到第 4 个号码。
- 检查范围要用 `index >= length`。输入刚好等于表长时，已经越界。
- 输入 `abc` 会在输出区看到「请输入一个整数下标」。这是程序用 `cout` 打印的提示。

## 动手练习

### 基础练习

分别输入 `0`、`3`、`4` 和 `-1`。先预测结果，再点运行对照。

### 进阶练习

直接读一格时，只访问一次数组。想一想，如果已知的是号码 `30`，却不知道它在哪一格，你会怎么找？下一课要学习的是在已知下标的位置加入一个号码。
