# 用 for 重复几次

如果练习教室要给前三张桌子编号，就可以让程序依次取到 1、2、3。`range(1, 4)` 从 1 开始，走到 4 前停下。这里把 4 写成 `n + 1`，输入改变时上限也跟着变。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_for_range.py`。

```python
# 从 1 开始，逐行打印到 n。
n = int(input())

for number in range(1, n + 1):
    print(number)
```

1. `n` 保存用户希望打印到的数字。
2. `for number in range(1, n + 1)` 每轮把读到的下一个整数交给 `number`。
3. 缩进的 `print(number)` 是循环体，每一轮执行一次。输入 0 时，`range(1, 1)` 没有值，循环体执行零次。

## 示例输入与输出

输入

```text
3
```

输出

```text
1
2
3
```

## 常见错误

- `range(1, n)` 在 `n` 前停止，会少打印最后一个数。
- 忘记缩进会让 Python 无法识别循环体。

## 动手练习

### 基础练习

输入 1、3、0，先数出会打印几行，再验证。

### 进阶练习
