# 读、改、追加与删除

列表用方括号保存多项数据。和字符串一样，位置从 0 开始。列表还允许把某一格换成别的值，也能添加或删除一格。

| 操作后 | 列表内容 |
| --- | --- |
| 改第 2 项 | `[20, 25, 10]` |
| 追加 5 | `[20, 25, 10, 5]` |
| 删除第 1 项 | `[25, 10, 5]` |

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_list_basics.py`。

```python
# 记录三次练习的分钟数。
minutes = [20, 15, 10]
print(f"第一项 {minutes[0]}")

minutes[1] = 25
minutes.append(5)
del minutes[0]
print(minutes)
```

1. `minutes = [20, 15, 10]` 创建三项分钟数。`minutes[0]` 取到第一项。
2. `minutes[1] = 25` 替换第 2 项。
3. `minutes.append(5)` 把 `5` 加到末尾。
4. `del minutes[0]` 删除下标 0 的元素，后面的元素依次向前补位。

## 示例输入与输出

本例无需输入。

输出

```text
第一项 20
[25, 10, 5]
```

## 常见错误

- `del minutes[0]` 用位置删除。这里的 `0` 表示第一格。
- 三项列表的有效非负下标是 0、1、2。赋值给 `minutes[3]` 会越界，添加末尾请用 `append()`。
