# 认识类型与转换

例如借用物品时编号写成 `006`，测量某段绳子长度写成 `2.5`。编号要原样显示，长度需要参与计算。可以为两项数据分别选择合适的类型。

## 文字、整数和小数

| 类型 | 例子 | 用途 |
| --- | --- | --- |
| 字符串 `str` | `"006"` | 保留文字及书写形式，比如编号前的两个 0。 |
| 整数 `int` | `6` | 适合表示件数或次数。 |
| 浮点数 `float` | `2.5` | 本例用它表示带小数的长度。 |

`input()` 读到的都是字符串。保留原编号，同时可以用 `int()` 得到整数版本。长度用 `float()` 转换。输入小数时用英文半角小数点 `.`。

## 逐行读代码

完整程序在编辑区和 `examples/python_types.py`。

```python
ticket = input().strip()
length = float(input())
number = int(ticket)

print(f"原编号：{ticket}")
print(f"转成整数：{number}")
print(f"两段的总长度：{length * 2}")
```

| 语句 | 用自己的话读 |
| --- | --- |
| `ticket = input().strip()` | 读第一行并去掉两端的空白，保留中间的字面内容。 |
| `length = float(input())` | 读第二行，把长度文字转换成浮点数。 |
| `number = int(ticket)` | 把编号转换成整数，保存在另一个变量里。原来的 `ticket` 仍保存 `"006"`。 |
| 前两条 `print()` | 分别打印原编号和转换出来的整数，看清开头两个 0 去哪里了。 |
| `length * 2` | `*` 表示乘法。Python 先把长度乘以 2，再把结果放入句子并打印。 |

## 示例输入与输出

输入

```text
006
2.5
```

输出

```text
原编号：006
转成整数：6
两段的总长度：5.0
```

## 常见错误

- 对含有小数点的字符串 `"2.5"` 使用 `int()` 会得到 `ValueError`。读取小数用 `float()`。
- 忘记转换长度时，字符串乘 2 会重复文字。`"2.5" * 2` 的结果是 `"2.52.5"`。
- 用整数保存编号会去掉开头的 0。需要保留编号样式时，把原字符串保留下来。

## 动手练习

### 基础练习

输入 `012` 和 `1.5`，先预测三行结果再运行。把长度改成 `1,5`，观察错误发生在哪一行。

### 进阶练习

修改个人代码，计算三段的总长度。把句子里的“两段”和计算里的 `2` 一起改掉，用 `2.5` 核对结果是否为 `7.5`。

## 从输入格式决定类型

编号 `007` 保留为字符串，转换成 `int` 会变成 7。人数用 `int()`，带小数的长度可用 `float()`。`int("3.0")` 会报错，而 `int(float("3.9"))` 得到 3，因为它向零截断。先决定数据含义再转换，避免用转换顺手去掉重要信息。
