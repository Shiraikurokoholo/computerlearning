# 条件判断与输入检查

取号机只发 1 到 4 号。程序先检查输入有没有读到整数，再决定这个号码能否使用。

## 逐行读代码

完整程序在编辑区和 `examples/cpp_conditions.cpp`。

```cpp
std::cin >> number;
if (std::cin.fail()) {
    std::cout << "请输入整数。\n";
    return 1;
}

if (number < 1 || number > 4) {
    std::cout << "号码超出范围。\n";
} else {
    std::cout << "可以取号。\n";
}
```

- `if (条件)` 会先判断括号里的条件，成立才执行后面花括号里的语句。
- `std::cin >> number` 尝试读取整数。`std::cin.fail()` 检查这次读取是否失败，失败时才进入第一个 `if`。
- `std::cout` 把提示写到输出区。`return 1;` 提前结束 `main`，表示这次运行遇到问题。
- `number < 1` 是小于 1，`number > 4` 是大于 4。`||` 表示“或者”，两项只要有一项成立就进入这一分支。
- `else` 对应条件不成立时的另一条路。这时号码在 1 到 4 之间。

## 示例输入与输出

输入

```text
3
```

输出

```text
可以取号。
```

## 常见错误

- `< 1` 会保留 `1`，`<= 1` 会把 `1` 也拦掉。改条件后要检查边界号码。
- 将 `abc` 送给整数变量会触发第一条检查，网页会显示“请输入整数”。

## 动手练习

### 基础练习

分别运行 `1`、`4`、`5` 和 `abc`。判断每次走了哪条路。

### 进阶练习

把个人代码的允许范围改成 2 到 6。至少用 `1`、`2`、`6` 和 `7` 检查边界。
