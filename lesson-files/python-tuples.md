# 用元组保存一条记录

一条练习记录有主题和时长，这两项可以放进一个元组。元组建立后不能直接替换里面的某一格。`record[0]` 能读到主题，也可以一次把两项交给两个变量。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_tuples.py`。

```python
# 用一条记录保存主题与时长。
record = ("循环", 20)
topic, minutes = record
print(f"{topic} {minutes} 分钟")
```

1. `("循环", 20)` 把字符串和整数一起保存起来。两项之间的逗号将它们分开。
2. `topic, minutes = record` 按顺序把第一个值给 `topic`，第二个值给 `minutes`。这种写法叫拆包。
3. `print()` 将两个变量放进同一句输出。

## 示例输入与输出

本例无需输入。

输出

```text
循环 20 分钟
```

## 常见错误

- 拆包时左右的项数要相同。给两个值写三个接收变量会报错。
- `record[1] = 30` 会报错。若想换成另一条记录，可以创建新元组再赋给 `record`。

## 动手练习

### 基础练习

用 `record[0]` 和 `record[1]` 各打印一次，再与拆包得到的变量对照。

### 进阶练习

把 `("数组", 15)` 和 `("循环", 20)` 放进列表。用循环取出每条记录，在循环内部拆包并打印。
