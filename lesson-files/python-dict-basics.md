# 用键找值

列表是按位置找值，字典可以按名称找值。这里每个「主题」是一个键，每个「分钟数」是对应的值。查「数组」会得到 20。这个例子约定查不到时用 0。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_dict_basics.py`。

```python
# 根据输入的主题查询分钟数。
minutes = {"数组": 20, "循环": 10}
topic = input().strip()
result = minutes.get(topic, 0)
print(f"{topic} {result} 分钟")
```

1. 字典用大括号创建。`"数组": 20` 读作键「数组」对应值 20。
2. `strip()` 清理主题前后的空白。
3. `minutes.get(topic, 0)` 找键对应的值。键不存在时，返回提供的默认值 `0`。
4. 输出主题和分钟数。

## 示例输入与输出

输入

```text
数组
```

输出

```text
数组 20 分钟
```

## 常见错误

- `minutes["图"]` 会在键缺失时触发 `KeyError`。可以用 `get()` 处理预期允许缺失的查询。
- 给已有键赋值，例如 `minutes["数组"] = 25`，会替换原值。

## 查找键、缺失键和零值

`name in scores` 检查的是键。`scores[name]` 在键不存在时抛出 `KeyError`，`scores.get(name, 0)` 则返回默认值 0，原字典保持原样。有些已登记的分数也会是 0。如果题目要区分「未登记」和「成绩 0」，先用 `in` 检查。
