# 第一次运行 C++

从运行一份 C++ 程序开始。如果你已经能写简单的输入输出，可以直接选「C++ 基础学习」里的数组、循环或指针练习。数据结构课会链接到用得上的小课。

点「运行示例」就能看到两行结果。网页先把文本源码编译成程序，再运行编译后的程序。桌面上也可以打开 `examples/cpp_first_run.cpp` 查看同一份源码。

## 逐行读代码

```cpp
#include <iostream>

int main() {
    std::cout << "你好，C++！" << '\n';
    std::cout << (2 + 3) << '\n';
    return 0;
}
```

| 代码 | 作用 |
| --- | --- |
| `#include <iostream>` | 让程序可以使用标准输入和输出工具。 |
| `int main() {` | `main` 是程序开始的位置。花括号包住要执行的语句。 |
| `std::cout << "你好，C++！"` | `std::cout` 是输出工具，`<<` 把右边的内容交给它。双引号围住文字。 |
| `<< '\n'` | 输出一个换行。下一项内容从下一行开始。 |
| `(2 + 3)` | 加法先算出 `5`，再交给 `std::cout`。 |
| `return 0;` | 告诉系统程序顺利结束。 |

## 示例输入与输出

输入区留空。

输出

```text
你好，C++！
5
```

## 常见错误

- 引号、括号和行尾分号用英文半角符号。中文文字可以放在双引号中。
- 改了代码后，先保存个人副本，再用「VS Code 本地调试」中的命令运行。
- 某行报错时也检查它的上一行，少写分号时，编译器可能到下一行才发现。

## 动手练习

### 进阶练习

在 `return 0;` 前加一条输出，让程序在第三行显示 `开始学习 C++`。
