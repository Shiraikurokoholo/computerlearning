# 函数与返回值

用一个有名字的小步骤判断下标能不能用。传给它下标和表长，它就把判断结果交回来。同一个判断可以在不同地方调用。

## 逐行读代码

完整程序在编辑区和 `examples/cpp_functions.cpp`。它复用「条件判断与输入检查」的写法，读到一个整数后再调用这个函数。

```cpp
bool is_valid_index(int index, int length) {
    return index >= 0 && index < length;
}
```

- `bool` 表示结果只有两种，`true` 表示成立，`false` 表示不成立。
- `is_valid_index` 是函数名。`int index` 和 `int length` 是函数收到的两个整数，按括号内的顺序对应。
- `>=` 表示“大于或等于”，`&&` 表示“并且”。下标要同时满足不小于 `0`、小于表长。
- `return` 把判断结果交给调用它的位置。
- `bool valid = is_valid_index(index, 4);` 用输入的下标和固定表长 `4` 调用函数，把结果保存在 `valid`。`if (valid)` 就能用这个结果决定输出哪一句。

## 示例输入与输出

输入

```text
2
```

输出

```text
可以读取。
```

## 常见错误

- 调用时把下标和表长的位置写反，会检查另一组数字。
- `index < length` 可以拦住下标刚好等于表长的情况。把它换成 `<=` 会多放行一格。

## 动手练习

### 基础练习

依次测试 `0`、`3`、`4` 和 `-1`，看看函数会返回哪种结果。

### 进阶练习

把调用中的表长改成 `2`。用 `1` 和 `2` 核对，如果输入相同，下标是否合法还会受表长影响。
