# 用 for 重复执行

想依次打印 0 到 3，可以用一个变量记录当前数字，用一条 `for` 语句重复打印。

## 逐行读代码

编辑区中有完整程序，源文件是 `examples/cpp_for_loop.cpp`。

```cpp
for (int i = 0; i < 4; ++i) {
    std::cout << i << '\n';
}
```

| 位置 | 什么时候执行 |
| --- | --- |
| `int i = 0` | 循环开始时执行一次。`i` 从 0 开始。 |
| `i < 4` | 每一轮开始前检查。成立才执行循环体。 |
| `std::cout << i << '\n'` | 打印本轮的 `i`，然后换行。 |
| `++i` | 本轮结束后把 `i` 加 1，再回去检查条件。 |

打印 `3` 后，`i` 加到 `4`。这时 `i < 4` 不成立，循环结束。之后读顺序表时，`i` 会用来指出当前处理的是哪一格。需要向左走时，可以用 `--i` 每轮减 1。

## 示例输入与输出

输入区留空。

输出

```text
0
1
2
3
```

## 常见错误

- `i <= 4` 会让 `4` 也被打印。先写出你想处理的第一个和最后一个数字。
- `++i` 放在循环设置中时，循环体里再加一次会跳过数字。

## 动手练习

### 基础练习

在纸上写出每次检查条件时 `i` 的值，并圈出能进入循环体的值。

### 进阶练习

把个人代码改成依次输出 `3`、`2`、`1`、`0`。让 `i` 从 `3` 开始，每轮减 1，并在条件中考虑什么时候停止。
