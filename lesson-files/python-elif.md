# 三种情况如何选择

有了三种提示时，可以用 `elif` 在原来的两条分支之间插入另一个条件。把它读作「前面的条件都没通过的话，再试这个」。例如 84 先过不了 85 分的门槛，接着去看 60 分。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_elif.py`。

```python
# 先检查最高门槛。
score = int(input())

if score >= 85:
    print("熟练")
elif score >= 60:
    print("达到练习目标")
else:
    print("继续练习")
```

1. `score = int(input())` 读入整数分数。
2. `if score >= 85` 先检查 85 分。通过就打印「熟练」，后面的分支会跳过。
3. `elif score >= 60` 只在第一个条件失败时检查 60 分。这时分数已经确定小于 85。
4. `else` 接住两个条件都失败的情况。

## 示例输入与输出

输入

```text
85
```

输出

```text
熟练
```

## 常见错误

- 把 60 分的门槛写在前面时，85 分也会先匹配 60 分的分支。
- 用两个独立的 `if` 时，两次判断都可能执行。这里要在三个结果里只选一个。

## 动手练习

### 基础练习

分别手推并运行 59、60、84、85，指出每次先检查哪个门槛。

### 进阶练习

在个人副本中把「熟练」的门槛改成 90 分，测试 89 和 90。

## 从空白文件写分档程序

输入一个整数。90 及以上输出「优秀」，60 至 89 输出「通过」，其他输出「继续」。先纸上写出三个互不重复的区间，再把较高门槛放在前面。用 59、60、89、90 验收，每次只有一行输出。如果两条分支都符合，按代码顺序只走第一个匹配分支。
