# 合并两个有序顺序表

第一行是两张表的长度，随后分别给出两张已排序的表。`i`、`j` 分别指向各自的下一项。每轮取较小的项。某一张表结束后继续读另一张，每项只取一次。

## 逐行读代码

```cpp
#include <iostream>

int main() {
    int a[50], b[50], n, m;
    if (!(std::cin >> n >> m) || n < 0 || n > 50 || m < 0 || m > 50) return 0;
    for (int i = 0; i < n; ++i) if (!(std::cin >> a[i])) return 0;
    for (int i = 0; i < m; ++i) if (!(std::cin >> b[i])) return 0;
    int i = 0, j = 0;
    std::cout << "合并";
    while (i < n || j < m) {
        if (j == m || (i < n && a[i] <= b[j])) std::cout << ' ' << a[i++];
        else std::cout << ' ' << b[j++];
    }
    std::cout << '\n';
}
```

## 示例输入与输出

```text
2 2
10 30
20 40
```

输出

```text
合并 10 20 30 40
```

## 常见错误

先检查下标，再读取元素。`<=` 让两个值相同时优先取左表。

### 基础练习

先手推默认数据，再换用一个边界用例，核对每步状态。例如输入 `0 2 / 10 10`，预期为 `合并 10 10`。

### 进阶练习

从空文件写合并函数，把结果存进第三张容量足够的表。补测两张表都空、只空一张、两边有相同值。
