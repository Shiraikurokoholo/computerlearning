# 递归与调用栈

`sumTo(3)` 先等 `sumTo(2)`。到 0 返回后，结果按 `0 → 1 → 3 → 6` 逐层交回。每层都有自己的 `n`。读编译错误时先看文件、行号和首条诊断，再核对本行和上一行。

## 逐行读代码

```cpp
#include <iostream>

int sumTo(int n) {
    if (n == 0) return 0;
    return n + sumTo(n - 1);
}

int main() {
    int n;
    if (!(std::cin >> n) || n < 0 || n > 100) {
        std::cout << "无效输入\n";
        return 0;
    }
    std::cout << sumTo(n) << '\n';
}
```

## 示例输入与输出

```text
3
```

输出

```text
6
```

## 常见错误

递归需要基例，每次调用都要走向基例。练习少写一个分号后观察诊断常常指向下一行。

### 基础练习

先手推默认数据，再换用一个边界用例，核对每步状态。例如输入 `0`，预期为 `0`。

### 进阶练习

从空文件写递归输出 `3 2 1` 的程序，再交换打印与递归的顺序得到 `1 2 3`。
