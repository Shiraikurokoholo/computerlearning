# 用 if 和 else 做选择

上一节得到了比较结果。现在让程序根据结果在两句提示中选一句。60 分也达到练习目标。

## 先按规则走一遍

- 分数是 59，`score >= 60` 得到 `False`，输出「继续练习」。
- 分数是 60，比较结果得到 `True`，输出「达到练习目标」。

## 逐行读代码

```python
score = int(input())

if score >= 60:
    print("达到练习目标")
else:
    print("继续练习")
```

1. 先读入 0 到 100 的整数分数。
2. `if` 后面是要检查的条件。条件为真时，执行冒号下面缩进的语句。
3. 第一条 `print()` 缩进四个空格，属于 `if` 分支，负责输出达标提示。
4. `else` 与 `if` 对齐，条件为假时走这条分支。
5. 第二条 `print()` 同样缩进四个空格，属于 `else` 分支。本例每次只输出一句。

## 示例输入与输出

输入

```text
60
```

输出

```text
达到练习目标
```

## 常见错误

- `if` 和 `else` 这一行的末尾都需要冒号。
- 如果把分支里的 `print()` 顶格写，Python 就无法判定分支的内容。本例用四个空格缩进。
- 写成 `score == 60` 只会让正好 60 分走第一个分支，61 分也会落入 `else`。
