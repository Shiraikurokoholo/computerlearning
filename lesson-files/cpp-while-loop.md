# 用 while 按条件重复

先判断，再执行循环体。把变量从 3 追踪到 0。`cin >> n` 尝试读取整数，放进条件里可以检查是否读取成功。`--n` 等同于 `n = n - 1`。

## 逐行读代码

```cpp
#include <iostream>

int main() {
    int n;
    if (!(std::cin >> n) || n < 0 || n > 100) {
        std::cout << "请输入 0 到 100 的整数\n";
        return 0;
    }
    while (n > 0) {
        std::cout << n << '\n';
        --n;
    }
    std::cout << "结束\n";
}
```

## 示例输入与输出

```text
3
```

输出

```text
3
2
1
结束
```

## 常见错误

忘记更新 `n` 时，条件可能永远为真。

### 基础练习

先手推默认数据，再换用一个边界用例，核对每步状态。例如输入 `0`，预期为 `结束`。

### 进阶练习

从空文件写一个先读数量、再读取这么多个整数的程序。输入 `3 8 -2 0`，输出非负数的个数 `2`。
