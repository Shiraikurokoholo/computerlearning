# 去重与成员判断

集合适合回答「有几种」和「有没有」。「猫 狗 猫」出现了三个词，但只包含两种。集合保留不同的成员，无法按下标取第几项。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_sets.py`。

```python
# 统计不同的词，并检查里面有没有猫。
words = input().split()
kinds = set(words)
print(f"{len(kinds)} 种")

if "猫" in kinds:
    print("含猫")
else:
    print("不含猫")
```

1. `split()` 得到原始词列表。
2. `set(words)` 把列表里的词收进集合，每种词只保留一份。
3. `len(kinds)` 返回不同词的数量。
4. `"猫" in kinds` 检查成员是否存在，再按真假输出。

对 `first` 和 `second` 两个集合，`first & second` 取交集，也就是两边都有的成员。`first | second` 取并集，也就是至少一边有的成员。

## 示例输入与输出

输入

```text
猫 狗 猫
```

输出

```text
2 种
含猫
```

## 常见错误

- 空集合用 `set()` 创建。`{}` 会创建空字典。
- 集合展示的顺序不应当作运行结果的保证。需要核对时可以比较数量或检查成员。

## 动手练习

### 基础练习

### 进阶练习
