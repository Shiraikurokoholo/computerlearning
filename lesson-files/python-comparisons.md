# 比较与布尔值

上节课用 `int(input())` 把输入变成整数。这次读入一项练习分数，用它回答一个问题：达到了 60 分吗？

## 先猜三个结果

| 分数 | 达标情况 | 比较的结果 |
| --- | --- | --- |
| 59 | 差一分 | `False` |
| 60 | 刚好达标 | `True` |
| 61 | 超过目标 | `True` |

`True` 和 `False` 叫作布尔值，分别表示真和假。`>=` 读作“大于或等于”，所以正好 60 分也符合条件。

## 逐行读代码

```python
score = int(input())
reached_goal = score >= 60
print(reached_goal)
```

1. `int(input())` 读取输入并转成整数。本节输入 0 到 100 的整数。
2. 先算出右边的比较结果，再用一个等号把结果保存在 `reached_goal` 中。
3. `print()` 输出布尔值。下一节会用这个结果来选择输出哪句话。

## 示例输入与输出

输入

```text
60
```

输出

```text
True
```

## 常见错误

- `=` 给变量赋值，`==` 比较两边是否相等。可以分别读一遍 `score = 60` 和 `score == 60`。
- `score > 60` 会把正好 60 分排除在外。
- 布尔值的首字母要大写。加引号的 `"True"` 是一段文字。
