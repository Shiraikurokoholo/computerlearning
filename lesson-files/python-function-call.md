# 定义并调用函数

如果两处都要打印相同的提示，可以把操作取个名字。`def` 定义函数，后面写 `announce()` 就能请它执行一次。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_function_call.py`。

```python
# 定义一次，同一段操作可以用多次。
def announce():
    print("练习开始")

announce()
announce()
```

1. `def announce():` 定义名为 `announce` 的函数，本例括号为空，表示调用时无需传入数据。
2. 缩进的 `print()` 是函数体。Python 读到定义时先记下这段操作。
3. 顶格的 `announce()` 真正调用它。两次调用各打印一行。

## 示例输入与输出

本例无需输入。

输出

```text
练习开始
练习开始
```

## 常见错误

- 单写 `announce` 只引用函数，括号 `()` 才发起调用。
- 把调用写在定义之前，执行到调用时函数名还没有定义。

## 动手练习

### 基础练习
