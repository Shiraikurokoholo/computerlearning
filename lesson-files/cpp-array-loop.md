# 用循环处理数组

一张号码表有四个值。要把它们逐个读出来，循环变量可以直接当数组下标用。每走到一格，顺手把那一格累加到总和中。

## 逐行读代码

完整程序在编辑区和 `examples/cpp_array_loop.cpp`。

```cpp
int total = 0;
for (int i = 0; i < 4; ++i) {
    std::cout << values[i] << '\n';
    total = total + values[i];
}
```

- `total = 0` 从零开始累计。
- `i = 0` 从第一格开始，`i < 4` 保证只访问这四格。
- `values[i]` 读取本轮所在的格子。第一轮读 `values[0]`，第二轮读 `values[1]`。
- `total = total + values[i]` 先算旧的累计值加当前值，再写回 `total`。前两轮结束后，`total` 分别是 10 和 30。

顺序表的搬动也用 `i` 找格子。届时 `values[i + 1]` 会表示当前格右边的一格，`values[i - 1]` 会表示左边的一格。先用表格标出这一轮的 `i`，再代入表达式。

## 示例输入与输出

输入区留空。输出

```text
10
20
30
40
总和：100
```

## 常见错误

- 写成 `i <= 4` 会多访问一格。最后一格的下标是 3。
- 把 `total` 的初始化写进循环体，每轮都会重新从零开始。

## 动手练习

### 基础练习

手算四轮结束时 `total` 的值，和程序的最终结果核对。

### 进阶练习

把个人代码改成从下标 3 向 0 倒着读取。用 `--i` 递减，观察打印顺序和总和各有什么变化。
