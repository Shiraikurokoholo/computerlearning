# 计数与累加

累加像记账，每一笔都加到之前的总数上。计数只登记出现了几次。处理 1、2、3 时，可以盯住这两个变量。

| 处理完 | 当前总和 | 偶数个数 |
| --- | --- | --- |
| 1 | 1 | 0 |
| 2 | 3 | 1 |
| 3 | 6 | 1 |

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_loop_totals.py`。

```python
# 统计 1 到 n 的总和和偶数个数。
n = int(input())
total = 0
even_count = 0

for number in range(1, n + 1):
    total = total + number
    if number % 2 == 0:
        even_count = even_count + 1

print(f"总和 {total}，偶数 {even_count} 个")
```

1. 读取 `n`，让总和和偶数计数都从 0 开始。
2. 循环每拿到一个数，就先计算旧的 `total + number`，再把结果写回 `total`。
3. `number % 2 == 0` 表示能被 2 整除。只有为真时才让 `even_count` 加 1。
4. `print()` 在循环外，全部处理完才输出一次。

## 示例输入与输出

输入

```text
3
```

输出

```text
总和 6，偶数 1 个
```

## 常见错误

- 把初始值写到循环里面，会在下一轮清空之前的统计。
- 把 `print()` 缩进循环中，会每轮各输出一次。

## 动手练习

### 基础练习
