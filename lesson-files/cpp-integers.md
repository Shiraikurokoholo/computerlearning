# 整数变量与输入

上节课把固定文字交给 `std::cout`。现在让程序把输入区里的号码读到一个整数变量中，再打印这个号码。

## 逐行读代码

编辑区中有完整程序，源文件是 `examples/cpp_integers.cpp`。

```cpp
int number = 0;
std::cin >> number;
std::cout << number << '\n';
```

- `int number = 0;` 准备一个叫 `number` 的变量，用来保存整数。先给它一个初始值 `0`。
- `std::cin >> number;` 从输入区读取一个整数并写入变量。箭头指向接收数据的 `number`。
- `std::cout << number` 把变量中此刻保存的值输出。`number` 外面没有引号，输出的是它的值。

也可以单写 `number = 12;`。这个语句会把已有变量的值换成 `12`。

## 示例输入与输出

输入

```text
7
```

输出

```text
7
```

## 常见错误

- 写成 `std::cout << "number"` 会输出字母 `number`。要显示读到的值，用变量名。
- 这课先练习输入有效整数，例如 `0`、`7`、`-3`。无效输入的检查放在下一课。

## 动手练习
