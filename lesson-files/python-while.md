# 条件成立就继续

倒数可以把「还剩几秒」当作继续条件。`while` 在进入循环前检查条件，每轮结束后再检查一次。值从 3 变到 2、1、0，到了 0 就退出。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_while.py`。

```python
# 从指定的非负整数倒数。
remaining = int(input())

while remaining > 0:
    print(remaining)
    remaining = remaining - 1

print("结束")
```

1. `remaining` 保存当前还剩几秒。
2. `while remaining > 0` 检查现在是否该执行循环体。
3. 本轮先打印当前值，再减去 1。减法让下一次检查更接近结束。
4. 左边顶格的 `print()` 在退出循环后执行。

## 示例输入与输出

输入

```text
3
```

输出

```text
3
2
1
结束
```

## 常见错误

- 忘记减 1 会让正数一直满足条件，形成无限循环。发现后应停止程序。
- 把条件改为 `>= 0` 会额外打印一次 0。

## 动手练习

### 基础练习

分别预测输入 0 和 1 会打印什么，再运行核对。

### 进阶练习

用 `while` 从 1 数到 3。写下起始值、继续条件和每轮的更新，再动手。

## 条件写在循环开头

每轮先检查条件，再执行循环体。初始条件为假时可能一次也不执行。倒计时从 0 开始就直接结束。写循环时找出三件事。哪个变量在循环前初始化，怎样判断停止，每一轮在哪里改变这个变量。若只在某个分支改变它，想想走另一分支时会不会一直重复。
