# 按名字累计与遍历

如果想知道每种词出现几次，可以为每个词留一格计数。第一次遇到「猫」从 0 加到 1，再遇到时从 1 加到 2。

| 本轮的词 | 本轮结束后的计数 |
| --- | --- |
| 猫 | 猫 1 |
| 狗 | 猫 1，狗 1 |
| 猫 | 猫 2，狗 1 |

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_dict_counts.py`。

```python
# 数出每种词出现了多少次。
words = input().split()
counts = {}

for word in words:
    counts[word] = counts.get(word, 0) + 1

for word in counts:
    print(f"{word} {counts[word]} 次")
```

1. 把输入拆成词，准备空字典 `counts`。
2. 每轮先取当前词的旧计数，第一次遇到时得到 0，然后加 1 并写回同一个键。
3. `for word in counts` 按键首次插入的顺序遍历。
4. `counts[word]` 找到当前键的计数，这时候它一定已经存在。

## 示例输入与输出

输入

```text
猫 狗 猫
```

输出

```text
猫 2 次
狗 1 次
```

## 常见错误

- 用 `counts[word] + 1` 处理第一次出现的词会先遇到缺失键。
- 遍历字典时拿到的是键，再用该键读取值。

## 动手练习

### 基础练习

测试同一个词重复两次和空行，观察是否分别得到一行和零行输出。

### 进阶练习

修改输出，让程序只报告出现至少两次的词。用「猫 狗 猫」核对。
