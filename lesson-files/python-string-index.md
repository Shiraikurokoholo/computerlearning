# 文字的下标和切片

把 `Python` 的六个字符排在格子里，位置从 0 开始，所以 `text[0]` 对应 `P`。`text[:3]` 是切片，意思是从开头取到下标 3 前，取到的是 `Pyt`。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_string_index.py`。

```python
# 输入一行文字，可以是空行。
text = input()
print(f"长度 {len(text)}")
if len(text) > 0:
    print(f"首字符 {text[0]}")
print(f"前三字符 {text[:3]}")
```

1. `input()` 读取一行。`len(text)` 返回字符串的长度。
2. `if len(text) > 0` 确认至少有一个字符后，再用 `text[0]` 读取首字符。
3. `text[:3]` 取开头最多三个字符。就算只有一个字符或没有字符，切片也可以执行。空行最后会打印标签以及标签后的一个空格。

## 示例输入与输出

输入

```text
Python
```

输出

```text
长度 6
首字符 P
前三字符 Pyt
```

## 常见错误

- 把 `text[1]` 当成首字符会读到第 2 个字符。
- 空串的 `text[0]` 会触发 `IndexError`。先检查长度，或者用允许截短的切片。

## 动手练习

### 基础练习

分别输入 `Python` 和一个汉字。再用终端运行并直接按回车，检查长度为 0 时会显示哪些行。

增加一行输出 `text[1:4]`，先预测对 `Python` 会取到什么。
