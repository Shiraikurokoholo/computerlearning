# 跳过一轮或提前结束

遍历一排数字时，希望跳过 2，并且看到 5 后结束。`continue` 跳到下一轮，`break` 结束整个循环。输入规则固定，可以在纸上跟踪每轮。

## 逐行读代码

完整程序在编辑区，也可单独运行 `examples/python_loop_control.py`。

```python
# 试着打印 1 到 6 中符合规则的数字。
for number in range(1, 7):
    if number == 5:
        break
    if number == 2:
        continue
    print(number)
```

1. `range(1, 7)` 提供 1 到 6。
2. 取到 5 时执行 `break`，之后的 6 也不会处理。
3. 取到 2 时执行 `continue`，本轮的 `print()` 被跳过。
4. 剩下走到 `print()` 的是 1、3、4。

## 示例输入与输出

本例无需输入。

输出

```text
1
3
4
```

## 常见错误

- 把跳过 2 的 `continue` 换成 `break`，循环会在 2 停止。
- 把 `print()` 写在两个判断之前，2 和 5 都已经被打印出来。

## 动手练习

### 基础练习

用手指沿 1 到 6 走一遍，说出每个数是打印、跳过、停止，还是没有走到。

### 进阶练习

把两处条件都改为 `number == 3`，再交换两个判断的先后顺序，对照输出并解释 4 是否会打印。
